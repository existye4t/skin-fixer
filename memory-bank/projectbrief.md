# Project brief

Browser page that does what the Skin Fixer in cslol-go does: import a `.fantome` or extracted mod zip, run the pass, download a `.modpkg`.

The file never leaves the machine. The download keeps the original name, author, version, description, and cover from `META/info.json`.

Author: Umut, A.K.A. Exist. License: MIT. Languages: Turkish and English. Themes: light and dark.

Source of the desktop fixer: https://github.com/Aurecueil/Cs-lol-go
